Getting started

1 · Install

The only runtime dependency is tslib. It ships dual ESM + CommonJS through its exports map (import → a tree-shakeable ESM build, require → CommonJS, one shared set of .d.ts) and supports Node.js 20.19 and later (CI runs 20.19, 22 and 24).

2 · Enable decorators

Decorator syntax needs only experimentalDecorators. emitDecoratorMetadata and reflect-metadata are optional and purely cosmetic: together they fill the inferred Type column in generated docs from design:paramtypes, and nothing else — enforcement, every projection and the tool schemas read the reified descriptor, not reflected metadata. Any experimentalDecorators-capable compiler works; for that optional Type column, tsc, ts-node, ts-jest and SWC (legacyDecorator + decoratorMetadata) emit the metadata, while esbuild, Vite and Bun don't. The descriptor-first path (Verify, contract(), toolSchemaFrom) works with no flags at all.

Parameter constraints

Each one is a decorator for a parameter (@Between(1, 10)) and a descriptor in a namespace (NumberContracts.Between(1, 10)). Every predicate is total: a wrong-type value is a violation, never a TypeError.

The descriptor namespaces are also exposed through one fluent facade, Contracts, grouped by the type they constrain: Contracts.number.between(1, 10), Contracts.string.uuid(), Contracts.enum(['celsius', 'fahrenheit']), Contracts.nullable(Contracts.number.finite()). It is the same factories under one entry point — a second spelling, not a second implementation — usable anywhere a descriptor is.

Stacked decorators conjoin and evaluate top to bottom. @Positive() and friends were removed on purpose, because a name can't carry a boundary. Write @GreaterThan(0).

Composition

  • @ArrayOf(item, {minItems?, maxItems?}): every element satisfies item. A failure names the element's index.
  • @Dictionary(value): an open map of string keys to values matching value.
  • @Shape(FieldClass): a closed DTO validated against another class's contracted fields.
  • ObjectContracts.Fields({...}): an optional-aware object literal, with no class needed.
  • @Nullable(item): also accepts null. This is different from @Optional, which means the value may be absent.

Markers

MarkerEffect
@Optional()An absent argument is fine, and the parameter is dropped from the tool schema's required. If any inheritance level requires it, it stays required.
@Default(v)Publishes {default: v} into the schema and implies @Optional. It does not inject the value; the host applies it.
@Describe('…')The property's description, which the model reads.
@Tool('…')The tool's top-level description.

Pre- and postconditions

DecoratorWhenBlamesProjects
@EnabledWhen((self, ...args) => bool)before, reads statecallerno
@Requires((...args) => bool)beforecallerno
@Returns(descriptor)after, on the settled valuecalleeyes
@Ensures((result, ...args) => bool)after, on the settled valuecalleeno

All four stack on one signature. A guard that returns false means "not enabled"; a guard that throws is treated as a defect in the guard itself and propagates unchanged.

Pre-state capture: old

@Ensures also has an options form, @Ensures({ predicate, capture?, description?, id? }). When capture is given, capture(...args) runs at call entry; its deep-cloned, frozen result is passed to the predicate as old, ahead of the arguments. That lets a postcondition compare the final result against pre-call state, so a body that mutates one of its arguments can't mask its own violation. The same capture form is available on contract() and contract.checked's ensures.

Field contracts

Enforce has a method for every constraint (greaterThan, between, oneOf, uuid, arrayOf, shape, nullable and so on). CreateFieldDecorator(descriptor) wraps any descriptor, including your own. Field contracts are inherited: a subclass can strengthen them but never weaken them.

Working with values

Use these when there's no signature to decorate. They take the same descriptors and run the same oracles, as functions.

FunctionUse it for
Verify.check(d, name, value)Untrusted input as a value, such as an HTTP 400. Narrows unknown and reports path and expected.
Verify.that(d, name, value)The same check, but it throws, returning the narrowed value on success.
toolSchemaFrom({name, description, params}, opts)Tool schemas whose permitted values are known only at runtime.
contract(spec, fn)Enforcing params, requires, ensures and returns on a plain function, sync or async.
contract.checked(spec, fn)The non-throwing twin of contract(). Each call returns a ContractVerdict as a value instead of throwing, so a verdict consumer and a thrown violation can't disagree.
violationFromCheck(result)Emitting a functional refusal on the observation stream.
defineConstraint({...})Your own first-class constraint, which projects like a built-in.

contract.checked(spec, fn) is the non-throwing twin of contract(): it runs the same bands through the same oracles and builds any failure through the same builders, but each call returns a ContractVerdict as data rather than throwing, and it touches no global state (never the violation policy, never the sink). A verdict is {ok: true, value} on success, {ok: false, band, index, id?, facts, value?, message} on a contract failure, or {ok: false, band: 'body', error} when the body itself throws. It carries the settled return and a localized path, and {evaluate: 'all'} collects every failure rather than only the first. Because both paths share those builders, a verdict consumer and a thrown violation can't disagree.

To try this live, use the playground.

Configuration

Set these once at startup. They're process-level, not per-request.

CallEffect
setViolationPolicy('throw' | 'warn' | handler)'warn' proceeds into the method. Use it to stage a new contract over live traffic.
setEnforcementMode('development' | 'production' | 'auto')Production strips assert-trust contracts. guard contracts stay on.
setDefaultTrust('guard' | 'assert')The default for contracts that don't declare one.
disableGuardEnforcement({confirm, reason})The only way to strip guard contracts.
setValueDisclosure('none' | 'all')Shows raw values in adorn's own output, for local debugging only.
setContractDiagnosticsEnabled(bool)Dev-mode warnings, such as constraints declared without @Contract().

Privacy

Redaction is on by default and needs no annotation. @Sensitive() on a field, parameter or class vetoes disclosure even under setValueDisclosure('all'). @Telemetry.value(), .redact(strategy) and .result() opt values into the observation path.

A permanent gap

transfer(ssn: string) has to be marked on the parameter itself. JavaScript's value semantics break the link back to a @Sensitive field once the primitive is passed.

CLI

docs and schema load, then project: they require each entry so its decorators run, which means importing executes the module, side effects included. .ts entries need ts-node and typescript in your project. check is static: it never runs your code, and it exits non-zero if it finds a leak.

Add-ons

Both ship inside the package as subpath exports. Importing the root never loads them, and each one needs its peer dependency only when you use it.

adorn/test

Needs fast-check. fuzzMethod, fuzzClass and fuzzFunction (each with an async variant) test one unit against its own contract. fuzzSequence tests call sequences on stateful objects.

adorn/otel

Needs @opentelemetry/api. createOtelSink() turns the observation stream into spans, a duration histogram and value-free violation events.

Gotchas

  • @Contract() is required. Without it, constraints are neither enforced nor projected. adorn warns in development.
  • Decorator order with @Validate(). Method decorators it should see must sit below it. Class-level @Contract() doesn't care about order.
  • TypeScript defaults are honored. f(@GreaterThanEqual(1000) t = 30_000) called as f() uses the default. @Default exists to publish a default to the schema.
  • A TypeScript default and @Default can disagree. @Default(10) x = 20 publishes 10 and runs with 20. adorn doesn't reconcile the descriptor with TypeScript.
  • No constructor-parameter decorators yet. Use a @Validate()-decorated static of(...) factory with a private constructor.
  • static #private blocks class decorators (TS18036). Move it to module scope.
  • @NotEmpty() accepts whitespace. Pair it with @Matches(/\S/) when blank input should fail.
  • A wrapped method reports length === 0. Its .name is correct, and contract() preserves length.
