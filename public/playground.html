This sandbox runs adorn itself — installed from npm into a real Node toolchain, decorators and all, not a re-implementation. Change a constraint on the declaration and re-run: the tool schema an LLM would read and the runtime check a reply must pass move together, because both are derived from that one declaration.

DECORATORS

The ergonomic form

The sandbox uses the decorator syntax from the hero — @NotEmpty(), @Between(1, 7) — running under a real TypeScript toolchain, which a browser-only fiddle can't do.

DESCRIPTORS

No decoration point needed

The same run shows the descriptor-first path: Contracts.number.between(1, 7) fed to Verify.check, for raw unknown off the wire or a per-session enum.

EDIT · RE-RUN

Watch both sides move

Change @LessThanEqual(7) to 14, or edit a reply, and re-run. The schema's maximum and the verdict on the reply change together — that's the no-drift point, live.
